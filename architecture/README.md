## Architecture documents

- [architecture/02-context-and-sensing.md](02-context-and-sensing.md) — sensing, context capture, and interpretation
- [architecture/03-runtime-orchestration.md](03-runtime-orchestration.md) — orchestration and task routing between devices
- [architecture/04-data-and-memory.md](04-data-and-memory.md) — memory, knowledge representation, and data governance
- [architecture/05-agents.md](05-agents.md) — multi-agent orchestration and agent responsibilities

These documents should be read alongside the research documentation in [docs/](../docs/).
