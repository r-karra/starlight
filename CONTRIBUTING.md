# Contributing

## Overview
This repository is a documentation-first research platform for Starlight. Contributions should strengthen the research narrative, architecture reasoning, and documentation quality.

## Expectations
- Keep writing clear, structured, and professional.
- Favor evidence-based design language over speculative implementation claims.
- Preserve the distinction between Today, Research, and Vision.
- Keep the work focused on documentation and diagrams rather than application code.
- Frame OS customization as an AOSP-based future direction and describe a prototype path on existing devices first. Keep the wording aligned with the realistic prototype framing: prototype on existing Android/XR platforms first; explore AOSP-based customization only for future reference hardware or open components.

## Workflow
1. Review the documentation map in [docs/](docs/).
2. Propose updates through a pull request or issue.
3. Maintain links, terminology, and structure across the documentation set.
4. Keep new material aligned with the long-term research focus of Starlight.
