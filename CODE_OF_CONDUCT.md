# Code of Conduct

## Purpose
This repository is intended to support respectful, collaborative, and intellectually honest research work.

## Standards
- Be respectful and constructive in all discussions.
- Avoid harassment, discrimination, or disruptive behavior.
- Encourage thoughtful collaboration across technical and non-technical contributors.

## Enforcement
Reports of unacceptable behavior should be shared with the repository maintainers for review and appropriate action.
