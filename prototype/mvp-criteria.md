# MVP acceptance criteria

## Purpose
Define what counts as done for the first prototype.

## Core MVP outcomes
The first prototype is successful if it can:
- capture lecture or research input on XR glasses
- process the input with an AI summarization or refinement service
- create a task/reminder or study note on the mobile companion
- sync selected context to a laptop for review
- preserve explicit user consent for capture and sharing

## Acceptance criteria
- [ ] A student can capture a lecture and later retrieve a concise summary.
- [ ] A task or reminder can be created on the phone from captured content.
- [ ] The phone can sync selected content to the laptop.
- [ ] The system shows a consent prompt before processing captured content.
- [ ] The experience uses minimal notifications and feels calm.

## Validation checks
- test the end-to-end student capture workflow
- verify the research request workflow on XR glasses
- evaluate the mobile/laptop handoff path
- collect user impressions of interruption, trust, and usefulness

## Out of scope for MVP
- full OS-level customization
- large-scale model training or offline AI infrastructure
- broad multi-device notifications and scheduling features
- advanced personalization beyond the first workflow
