# Phase 2: Cross-device orchestration

## Objective
Add explicit handoff and context coordination across glasses, phone, laptop, and cloud.

## Goals
- Implement device routing rules for when the glasses, phone, or laptop should act.
- Add a research assistance workflow that refines a topic request through AI.
- Improve continuity so a task created on one device can be resumed on another.

## Milestones
- [ ] Define handoff rules and consent boundaries for cross-device sharing.
- [ ] Implement a research request path from XR glasses through phone and cloud.
- [ ] Add laptop review for deeper summaries and task context.
- [ ] Validate the handoff workflow with a student or knowledge worker scenario.

## Notes
The focus should be on seamless state transfer and explicit user control, not full feature breadth.
