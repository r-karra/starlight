# Phase 1: Companion capture

## Objective
Build the first working prototype for XR capture, mobile companion orchestration, and basic cross-device continuity.

## Goals
- Demonstrate lecture capture and summary generation from an XR or mobile capture source.
- Create a mobile companion workflow for task creation, reminders, and privacy consent.
- Sync captured context to a shared state so the laptop can later continue the task.

## Milestones
- [ ] Choose a target XR/R&D device and confirm available capture APIs.
- [ ] Build a minimal Android companion app for receive/display and consent management.
- [ ] Implement a simple cloud or local backend for task/context sync.
- [ ] Add a summary generation flow using an AI summarization API.
- [ ] Validate an end-to-end student capture workflow: capture → summary → task/reminder.

## Notes
Keep the scope small and focused on building one end-to-end experience. Do not attempt OS-level customization in this phase.
