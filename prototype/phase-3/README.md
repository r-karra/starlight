# Phase 3: Stress reduction and reflection

## Objective
Add calm support, low-friction reminders, and values-aligned reflection to the prototype.

## Goals
- Introduce features that help reduce notification overload and screen dependency.
- Add contextual reflection prompts that emphasize family, faith, nature, and personal priorities.
- Validate whether the system feels less intrusive and more supportive.

## Milestones
- [ ] Define stress-reduction and reflection triggers for the prototype.
- [ ] Implement gentle reminders and optional reflection prompts.
- [ ] Add metrics collection for perceived stress and trust.
- [ ] Validate the experience with users in student or job-holder scenarios.

## Notes
This phase is about experience quality and alignment with the broader mission, not adding more complex capture features.
