# User flows

## Purpose
This document captures the most important prototype workflows for students, job holders, and values-oriented support.

## Student capture workflow
1. The student uses XR glasses to record lecture audio or capture notes.
2. The mobile companion receives the capture and asks for consent to process it.
3. The cloud service summarizes the lecture and extracts key points.
4. The phone creates a study note, calendar event, or reminder and syncs it to the laptop.
5. The student can later review the refined summary on the laptop.

## Research assistance workflow
1. The student asks the glasses: "Help me research this topic."
2. The glasses send the request and captured context to the phone.
3. The phone forwards the request to an AI service.
4. The AI service returns a refined explanation, references, and next-step suggestions.
5. The glasses present the result with the option to open a deeper review on the laptop.

## Work continuity workflow
1. The user creates a task through voice or command on the glasses or phone.
2. The phone stores the task and syncs it to the laptop.
3. The laptop shows the task details and any related context.
4. The user resumes the task on the laptop and marks progress or completion.

## Calm reflection workflow
1. The system detects a high-interruption state or a period of sustained screen use.
2. The companion suggests a calm reminder or reflection prompt.
3. The user can choose a short action aligned with family, community, nature, or faith.
4. The system avoids additional distracting notifications and keeps the prompt gentle.

## Consent and privacy workflow
1. Whenever the glasses capture audio or notes, the system asks the user to approve processing.
2. The user can choose which captured items are shared across devices.
3. The phone shows a summary of synced items and allows the user to revoke sharing.
4. The system keeps the user in control of what flows between glasses, phone, laptop, and cloud.
