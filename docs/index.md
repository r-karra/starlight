# Documentation index

## Purpose
This index provides the primary entry point for the Starlight Platform research platform. It organizes the documentation into a layered narrative covering the present, the research frontier, and the long-term vision.

## Background
The documentation set is designed to help readers move from a high-level concept to detailed design thinking without losing sight of the platform’s boundaries. The index therefore acts as both a map and a guide for the repository’s research posture.

## Goals
- Help readers navigate the documentation in a logical sequence.
- Clarify how the Today, Research, and Vision layers relate to one another.
- Point to the most relevant documents for product, architecture, and research questions.

## System design
The documentation is organized into three layers:
- Today: prototype the experience on existing XR-capable devices and companion applications.
- Research: examine context memory, multimodal capture, personalization, agentic workflows, and research access orchestration.
- Vision: define the longer-term path for reference hardware and AOSP-based platform exploration.

## Key workflows
- Start with the overview docs and move outward into the mode-specific documents.
- Use the roadmap docs to connect present-day prototypes with future research directions.
- Return to the glossary and references when terminology or context needs clarification.

## Constraints
- The repository is intentionally documentation-first and does not include application code.
- The content should remain realistic about what can be prototyped on current devices.
- The platform narrative should continue to distinguish prototypes from future hardware and platform concepts.

## Future work
Future work should expand the documentation with deeper research notes, annotated references, and additional diagrams as the platform evolves.
