# Glossary

## Purpose
This glossary defines core terms used throughout the Starlight documentation set.

## Background
An emerging platform benefits from a shared vocabulary so that research, architecture, and design discussions stay consistent. The glossary helps connect the Today, Research, and Vision layers by making the terminology precise and reusable across the documentation set.

## Goals
- Define important terms in plain language.
- Keep the terms aligned with the documentation’s layered structure.

## System design
- Ambient intelligence: a computing model that helps users in the background through context-aware assistance.
- Cross-device orchestration: the coordination of tasks and context across glasses, phone, laptop, and cloud.
- AOSP-based strategy: a research-oriented path that explores Android Open Source Project customization for future reference hardware.
- Context memory: stored information that helps the system maintain continuity across tasks and sessions.
- Multimodal capture: the use of speech, vision, text, and sensor data in combination.

## Key workflows
- Use the glossary to interpret the core architecture and mode-specific docs.
- Keep terminology consistent in new research notes and diagrams.

## Constraints
- Terms should remain simple and accessible while preserving technical precision.

## Future work
Future work should extend the glossary with terminology from privacy, hardware, and AI research.
